## 1. 원칙 충돌을 어떻게 푸는가

2세대 문서가 명시적으로 금지한 것:

> *"스트레스성 소비일 확률 85%처럼 사용자의 심리상태를 단정하지 않는다."*

그런데 "충동소비를 판단하고 싶다"는 요구는 정당하다. **둘 다 만족시키는 방법은 충동성을 심리가 아니라 행동으로 조작적 정의(operationalize)하는 것이다.**

| | 금지되는 표현 | **허용되는 표현** |
|---|---|---|
| 대상 | 마음 상태 | 관측된 행동 |
| 예 | "스트레스 받아서 사셨네요" | "야간 + 직전 결제 15분 후 + 재량지출" |
| 검증 | 불가능 | 거래 원본으로 즉시 확인 가능 |
| 반박 | 못 함 | 사용자가 "아니야"라고 정정 가능 |

**UI 카피 규칙:** `충동적이었습니다` ❌ → `충동 소비의 특징 3개 중 2개에 해당합니다` ✅

## 2. 산식

```
Impulse = night(20) + burst(20) + deviation(25) + rapid_repeat(15) + discretionary(20)
```

| 축 | 정의 | 왜 이게 충동의 지표인가 |
|---|---|---|
| `night` | 22:00~04:00 결제 | 의사결정 품질 저하 시간대 |
| `burst` | 직전 **능동** 결제로부터 60분 이내 (다른 가맹점) | 연쇄 결제 = 계획 부재 |
| `deviation` | 동일 카테고리 중앙값 대비 초과 배수 | 평소 패턴 이탈 |
| `rapid_repeat` | 24시간 내 동일 브랜드 재결제 | 억제 실패 |
| `discretionary` | 재량지출 카테고리 여부 | 필수 지출은 충동이 아니다 |

### ★ Planned Gate — 이게 핵심이다

```python
if tx.is_recurring or tx.category in PLANNED:   # 교육·통신·보험·의료·정기권·행정
    score = min(score, 20)
```

**고액이라고 충동이 아니다.** 검증 결과가 이걸 증명한다:

| 거래 | 금액 | 점수 | 밴드 |
|---|---|---|---|
| 금융투자교육원 (자격증 교육비) | **118,000원** | **20** | 계획 |
| 금융투자교육원 | 95,000원 | 11 | 계획 |
| **다이소** | **1,000원** | **55** | **주의** |

> **1,000원짜리가 118,000원짜리보다 3배 높은 충동 점수를 받는다.** 이게 "금액 나열형 가계부"와 갈리는 지점이고, 시연에서 가장 설득력 있는 한 장면이다.

`burst` 기준선에서 **자동이체(통신·보험·정기권)를 제외**한 것도 같은 이유다. 보험료가 빠져나간 4분 뒤 배달을 시켰다고 해서 그게 연쇄 결제는 아니다.

## 4. 검증에서 드러난 문제 3개 (정직하게)

> **✅ 문제 1·3은 세션 채점 도입으로 해결됐다** (`backend/app/engine/session.py`).
> 건별 최고는 여전히 55점이지만, 세션 단위로는 **76점 "충동 패턴"**이 잡힌다:
> `분99 → 올리브영 → 다이소 / 62분 3건 28,000원 / 야간 시작 22:27`.
> 아래 두 항목은 그 판단에 이른 기록으로 남긴다.

### 문제 1 — "충동 패턴"(60점 이상) **0건** *(건별 채점 기준 — 세션 채점으로 해결)*

최고가 55점이다. 두 가지 해석이 가능하고, **구분해야 한다.**

- (a) 이 데이터에 실제로 극단적 충동 소비가 없다 → 정상
- (b) 가중치가 잘못됐다 → 재조정 필요

현재로선 (a)로 보인다. 다만 **시연용 fixture에는 명백한 충동 케이스를 의도적으로 심어야 한다.** 야간 + 고액 + 연쇄 + 반복이 동시에 걸리는 케이스가 없으면 최고 밴드가 화면에 안 나온다.

> 밴드 경계는 이 96건에 맞춰 보정한 값이다. **고정 상수로 취급하지 말 것.**

### 문제 2 — 🔴 카테고리 미상 26%가 판정을 무력화한다

**가장 중요한 발견이다.**

- 96건 중 **25건(26%)이 `unknown`** — 룰 사전으로 카테고리를 못 잡는다
- `unknown`이면 `discretionary`(20점)와 `deviation`(25점) **두 축, 총 45점이 통째로 죽는다**
- 즉 **충동 판정 만점의 45%가 카테고리 지식에 걸려 있다**

실제 피해 사례:
```
10/01 22:11  네이버파이낸셜  1,220,252원  ← 전체 최고액, 야간
             → 카테고리 미상 → 편차 판정 보류
```
전체 거래 중 최고액이자 야간 결제인데 **뭘 산 건지 몰라서 제대로 판정을 못 한다.**

**→ LLM 카테고라이저는 "있으면 좋은 것"이 아니라 충동 판정의 전제조건이다. P0.**

카테고리 미상 25건이 왜 룰로 안 잡히는지:
```
네이버페이                        ← 가맹점 정보 자체가 없음 (7건)
카카오페이_KPN-주식회사넌럭셔리어스컴   ← PG 뒤에 숨은 정체불명 상호
(주)정한솔루션 1,250원              ← 사람도 검색해야 앎
너와나 / 모퉁이네 / 콩심 / 분99      ← 개인 상호. 사전 불가
ATTIC IN SEOUL                   ← 영문 상호
```

### 문제 3 — 건별 채점이 실제 충동을 과소평가한다 *(세션 채점으로 해결)*

01/29 밤에 이런 일이 있었다:

```
22:27  분99        24,000원
23:14  올리브영      3,000원   (47분 후)
23:29  다이소        1,000원   (15분 후)
```

**개별로 보면** 24,000 / 3,000 / 1,000원이라 대수롭지 않다.
**묶어서 보면** "야간 62분간 3개 가맹점 연쇄, 28,000원"이다.

→ 사람이 "충동소비"라고 부르는 건 후자에 훨씬 가깝다. **다음 단계는 세션 단위 채점이다.**

## 5. 그래서 AI는 어디에 쓰이나 (3곳, 전부 필수)

| # | 역할 | 없으면 |
|---|---|---|
| **1. 카테고리 추론** | `unknown` 25건 해소 | **충동 판정 45%가 죽는다** (문제 2) |
| **2. 세션 해석** | 연쇄 결제 묶음을 서술 | 건별 나열에 그친다 (문제 3) |
| **3. 넛지 문구** | 밴드별 개인화 서술 | 템플릿 폴백으로 대체 가능 |

**1번이 압도적으로 중요하다.** 나머지 둘은 없어도 돌아가지만, 1번이 없으면 기능 자체가 성립하지 않는다.

### 세션 해석 프롬프트 규칙 (2번)

```
입력: 연쇄 결제 묶음 + 각 건의 지표 + 계산된 점수
출력: 2문장 이내

금지:
  - 심리 추론 ("스트레스", "외로움", "보상심리", "충동적으로")
  - 원인 단정 ("~때문에 사셨네요")
  - 숫자 생성 (입력에 있는 값만)
  - 훈계 ("줄이셔야 합니다")

허용:
  - 관측 서술 ("22시 27분부터 62분 동안 3개 가맹점에서 연속 결제가 있었습니다")
  - 목표 연결 ("이 패턴이 주 2회 유지되면 목표가 N일 늦어집니다")
  - 사용자 정정 유도 ("계획된 지출이었다면 알려주세요")
```

마지막 항목이 중요하다. **사용자가 "아니야, 계획된 거야"라고 정정하면 그 브랜드를 `PLANNED`로 학습**시킨다. AI가 단정하지 않는다는 원칙이 UX 기능으로 바뀐다.

## 7. ⚠️ 데이터 주의

`raw_card.txt`는 실제 카드 명세로 보인다.

- `연세위드유외과의원`, `에이치약국`, `대한피부과학연구소` — **의료 이용 기록**
- `LGUPLUS통신요금자동이체(93**67**)` — 부분 마스킹된 실번호
- 생활 반경 특정 가능 (외대·용산·여의도·목동)

**권고:** 깃 커밋·팀 공유·발표자료에 원본을 올리지 말 것. 시연 fixture는 **포맷의 지저분함(PG 접두, 표기 분산, 개인 상호)만 유지하고 가맹점·금액·날짜를 합성**하면 된다. AI 필요성 논증은 포맷에서 나오지 실제 값에서 나오지 않는다. 의료 거래는 제외하거나 일반 카테고리로 치환.

또 총액 368만/약 5개월인데 앞 구간(01/14~02/12) 한 달만 보면 약 216만 원이다. 페르소나 1(월 실수령 235만)과 대략 맞지만, 합성 시 페르소나 소득에 맞춰 조정할 것.
