## 이 저장소의 다른 구현과의 관계

같은 서비스를 두 갈래로 구현한 상태입니다. 목적이 다릅니다.

| | `site/` (이 디렉토리) | `backend/` |
|---|---|---|
| 언어 | JavaScript | Python (FastAPI) |
| 역할 | **실제 운영되는 화면** | AI 레이어·계산 엔진 설계 검증 |
| 테스트 | 없음 | 119개 (`python -m pytest tests`) |
| 부채 기능 | 슬라이더·입력폼·완납 비교까지 화면 구현 | `engine/debt.py` (API만) |

`backend/` 는 Numeric Guard·Tool-Use Agent 등 AI 설계를 검증하려고 만든
별도 구현이고, 화면은 `site/` 가 담당합니다. 두 코드는 서로를 호출하지 않습니다.

## 데이터 치환

원본의 `public/data/dummy_tx.txt` 는 실제 카드 명세라
**의료 이용 기록(외과의원·약국·피부과)과 부분 마스킹된 통신 번호**가 들어 있습니다.
공개 저장소에 중복 게시하지 않기 위해 **합성 데이터 102건으로 교체**했습니다.

- 포맷의 지저분함(PG 접두, 브랜드 표기 분산, 개인 상호, 간편결제 단독)은 그대로 유지 — AI 카테고라이저가 필요한 이유를 보여주는 특성이 여기서 나오기 때문
- 가맹점·금액·날짜는 전부 합성
- 생성 스크립트: 이 저장소의 `tools/build_fixture.py`, 원본 텍스트는 `fixtures/demo_card.txt`

따라서 이 사본으로 FinTox 화면을 돌리면 원본과 **숫자가 다릅니다.**
원본 수치가 필요하면 `lhy0205/blue` 를 직접 받으세요.
